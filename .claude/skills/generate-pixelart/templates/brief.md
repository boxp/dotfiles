# ドット絵 brief（生成前に埋める）

| 項目 | 値 |
| --- | --- |
| 用途 | 例: 会話ウィンドウの顔グラ / Even G2 の立ち絵 / GBA スプライト |
| 実表示サイズ | 例: 80x80 を 1x と 4x（320x320）で nearest 表示。CSS px / device px との一致は保証しない |
| 論理 pixel grid（canvas） | 例: 80x80 |
| anchor / framing | 例: 頭頂を上端基準、水平中央。頭頂〜マフラーまで |
| パレット | 例: 24 色以内、dither 無し / 固定パレットのファイル |
| 輪郭 | 例: 外側 1px 暗色、内側は色境界のみ |
| 光源 | 例: 左上。影 1 段 + ハイライト 1 段 |
| 透過 | 例: キー色 #00FF00 → alpha 0/255 |
| 背景 | 例: 無し（透過） |
| キャラ / ポーズ | 設定ファイルがあれば全文をプロンプトに含める |
| 差分 | 例: 驚き・笑い。変えてよい部位: 目・眉・口。合成矩形は基準採用後に決める |
| profile | generic（カラー） / g2-green16（floor・gamma の初期値） |
| 検査しきい値 | 例: 色数 ≤ 24、孤立率 ≤ 2%、差分漂流 ≤ 10%、G2 コントラスト ≥ 100 |
| 保存先 | 作業: /tmp/pixelart-<name>/、最終: <ユーザー指定> |
